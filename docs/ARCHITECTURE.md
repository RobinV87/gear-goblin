# Architecture

Milestone 1A is a browser application. React renders the interface; device validation and the repository contract are separate from presentation. The browser adapter uses Dexie over IndexedDB, with UUID keys and a versioned schema. Version 2 adds device-related firmware, storage, accessory and modification records; deleting a device and its related records uses one transaction. No network service is involved at runtime.

The future Android adapter must implement the same application-facing contract using native SQLite, with explicit migrations, transactions and tested import/export. Browser and native storage are separate physical databases: moving data between them needs a deliberate backup/migration workflow. Images and other remaining entities require a schema and lifecycle design in later milestones; they are not silently represented by the current device model. Browser storage can be evicted or cleared, and no backup exists yet.

Navigation currently uses local UI state. Native back handling, lifecycle, permissions, file access, accessibility refinement and device testing remain Android work. The UI uses a small token-like palette in CSS, with a light theme planned. No studio-wide framework is required; proven patterns or components can later be extracted into independent packages when another product actually needs them, without tying products to a monorepo or backend.
