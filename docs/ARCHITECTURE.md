# Architecture

Milestone 1C is a browser application. React renders the interface; device validation and the repository contract are separate from presentation. The browser adapter uses Dexie over IndexedDB, with UUID keys and a versioned schema. Schema version 2 adds workshop records keyed by device ID. Schema version 3 adds one optional photo per device. Deleting a device removes its workshop records and photo in the same transaction. No network service is involved at runtime.

The future Android adapter must implement the same application-facing contract using native SQLite, with explicit migrations, transactions and tested import/export. Browser and native storage are separate physical databases: moving data between them needs a deliberate backup/migration workflow. The version 1 backup format is a ZIP with a JSON manifest and separate photo files. Import checks archive paths, sizes, checksums, manifest schema, duplicate IDs and device references before preview. A confirmed restore replaces all three tables in one transaction. Browser storage can be evicted or cleared, so the exported ZIP provides a separate recovery copy.

Navigation currently uses local UI state. Native back handling, lifecycle, permissions, file access, accessibility refinement and device testing remain Android work. The UI uses a small token-like palette in CSS, with a light theme planned. No studio-wide framework is required; proven patterns or components can later be extracted into independent packages when another product actually needs them, without tying products to a monorepo or backend.
